# Claude Code remote control

## Objective

Create a document or documents with the corresponding details to instruct a developer to integrate Claude Code with a 
messages app.


## Requirements

* As a user, I want to be able to send a message to Claude Code, by text or sending an audio voice. Also attach files 
in my message.
* As a user, I want to get responses from Claude Code, by text through a message app.


## Delivery

* Spec document or documents with the details of the analysis that later will be handed to a developer to be built.


## Specification

* It will run on a Kubuntu 26.04 LTS.
* WhatsApp or a self-developed app. The message app will run on an Android device.
* Only using Claude Code Pro subscription
* Not Public IP or VPS available.
* Not conding language preference.
* Use mature libraries, frameworks or public projects, if needed.
